# 实体 iPhone 验收清单

以下验收需要实际安装应用；未执行时不得填为通过。自动化测试的受控 transport 仅用于 XCTest 验证资源释放、终态竞态及错误传播，生产始终使用 NWConnection。

| 场景 | 操作与期望 | 验证层 |
| --- | --- | --- |
| 真实 TCP 成功 | CI 在本机 NWListener / NWConnection 回环建立 TCP，确认成功、非负且小于超时的单调计时 | 原生单元测试 |
| 实际 Apple 目标 | iPhone 测试公开域名 443，查看真实耗时、接口和错误，无假数据 | 真机待验证 |
| 超时 | 受控 transport 不进入 ready，确认计时器只结束一次并关闭连接；真机使用自行管理的静默丢弃端口复验 | 单元测试 + 真机 |
| 取消 | 受控 transport 检查取消一次、清空状态回调、不允许重新 start；iPhone 在连接和间隔中分别取消 | 单元测试 + 真机 |
| DNS 失败 | 单元测试注入 NWError.dns；真机对唯一 `.invalid` 域名测试，保留 DNS 错误或 waiting 超时原因 | 单元测试 + 真机 |
| 拒绝连接 | 自己控制的服务器关闭测试端口，iPhone 显示系统错误而不是零延迟成功 | 真机待验证 |
| 网络切换 | 单元测试取消后送达 late ready，回调只发生一次；真机在测试及间隔中切 Wi-Fi，测试中断不崩溃 | 单元测试 + 真机 |
| 无持续连接 | 前端测试最后一次后不再等待、取消后不开始新采样；真机结束后确认进度停止、不自动续跑 | 单元测试 + 真机 |
| 手动保存 | 测试完成不会增加历史；保存弹窗命名，确认后出现；不保存不新增历史 | 真机待验证 |
| 持久化 | 完成命名保存，退出再启动保留原样本；测量中强制终止后恢复待保存记录，无自动假成功 | 真机待验证 |
| 对比与排序 | Wi-Fi / 蜂窝分别完成同参数测试，检查 P95、波动、失败率、排序与原始采样一致 | 前端测试 + 真机 |
| 后台生命周期 | 锁屏、切换应用会中断，本轮部分采样可选择保存，返回后不自动继续 | 真机待验证 |
| HTTPS | HEAD 请求、正常证书验证、无缓存/凭据，核对 DNS/TCP/TLS/TTFB、状态码、重定向、HTTP/2/3与不可用值 | 真机待验证 |
| 文件恢复 | 导出 JSON，通过“文件”分享，清理测试记录后导入恢复；CSV 用表格工具查看编码 | 真机待验证 |

Apple 公开站点受到 CDN、DNS 缓存、限流、HEAD 支持程度及实际服务器负载影响。请低频串行操作，失败也是有效诊断结果，不通过重试刷请求来制造成功。
